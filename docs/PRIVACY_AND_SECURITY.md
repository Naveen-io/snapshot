# FROSTEX ORBIT — PRIVACY & SECURITY SPECIFICATION

## 1. Local-First Privacy Policy
- **Zero Cloud Transmission**: FROSTEX ORBIT operates 100% locally on the host machine. It initiates zero outgoing HTTP/HTTPS/WebSocket requests to external servers. No telemetry, crash reporting, or analytics are collected or transmitted.
- **Zero Raw Video or Audio Persistence**: Camera frames and microphone audio streams are processed exclusively in volatile system RAM and discarded immediately after landmark / feature extraction. No video files, raw frame dumps, screenshots, or audio recordings are ever written to the local disk, event logs, or diagnostic bundles.
- **Diagnostics Boundary**: Event logs contain only monotonically increasing timestamps, mode state changes, measured frame rates (FPS), latency measurements, and sanitized error messages.

## 2. Windows Desktop Security Boundaries
- **Standard User Execution**: ORBIT does not request or require Windows Administrator elevation (`runas`). All pointer injection uses standard Windows `SendInput`.
- **UIPI (User Interface Privilege Isolation)**: Windows prevents standard-integrity applications from injecting input into higher-integrity (Elevated/Admin) windows (e.g. Task Manager, elevated cmd/PowerShell). When the user focuses an elevated window, Windows will silently ignore injected input. ORBIT documents this behavior and will never prompt the user to disable UAC or elevate ORBIT.
- **Strict Allowlist for Voice & Shortcuts**: ORBIT explicitly forbids arbitrary natural language to shell execution. Spoken commands are mapped to a compile-time static allowlist (e.g. `PAUSE_ORBIT`, `OPEN_SETTINGS`, `CENTER_POINTER`). Gestures can never delete files, run scripts, modify registry keys, or alter system security settings.

## 3. Inter-Process Communication Security
- **Loopback Binding**: Inter-process communication between the Electron desktop shell and the Python vision service binds strictly to `127.0.0.1` (localhost). It never listens on `0.0.0.0` or exposes interfaces to the local network (LAN).
- **Session Authentication Token**: A cryptographically secure 256-bit random token is generated by the Electron main process at startup and passed to the Python child process via standard environment variable (`ORBIT_SESSION_TOKEN`). Every IPC request must supply this token in its handshake or headers.
- **Schema Validation**: All messages between processes must conform to the strict versioned schema defined in `packages/protocol`. Any payload with extra fields, non-finite numbers (NaN, Infinity), or unrecognized types is dropped immediately.
